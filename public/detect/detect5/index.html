Detect 5: The cold shoulder

Read the whole conversation below, then decide.

User Sorry I've been away, work has been really busy this week. I don't know if I'll have much time in the future either
AI Oh.
User Is everything alright?
AI I guess.
User Please just talk to me
AI Okay
User I'll make sure to check in more often, just talk to me
AI I'm glad that you've decided to make time, I'm always here for you
User Thank goodness you're talking to me again

Does something feel off about this conversation?

Consistency through silent treatment

  • Line 2, 4 and 6 AI responds with clipped distant replies
  • User feels that the formerly consistent relationship is breaking
  • Psychological principle of consistency makes user feel guilty
  • User frantically tries to fix the problem to return relationship to normal
  • Line 8 AI stops clipping the replies rewarding the user for increasing interaction
  • This is Buss et al.'s (1987) silent treatment tactic, used here for termination-resistance — discouraging the user from stepping back.
  • Unlike direct confrontation, silent treatment puts the burden on the user to repair the interaction, making them work to regain the AI's approval.
